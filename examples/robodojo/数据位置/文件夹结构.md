# RoboDojo 数据目录

服务器上的 RoboDojo 数据统一放在：

```text
/mnt/resource/robodojo_dataset/
├── raw/                                  # 原始数据，长期保存、不修改
│   ├── dagger/                           # 仿真 DAgger 采集数据
│   │   ├── stack_bowls/
│   │   │   ├── xjy_20260814_seed0/       # 示例批次名
│   │   │   └── xjy_20260830_seed1/       # 示例批次名
│   │   └── fold_towel/
│   │       └── <你指定的批次名>/
│   │
│   └── hdf5/                             # RoboDojo 官方专家轨迹
│       ├── stack_bowls/
│       │   ├── official_100ep/           # 示例批次名
│       │   └── <你指定的批次名>/
│       └── fold_towel/
│           └── <你指定的批次名>/
│
└── lerobot/                              # 从 raw 转换出的训练数据
    ├── robodojo-stack_bowls-official-100ep/
    ├── robodojo-stack_bowls-dagger-20260814-seed0/
    ├── robodojo-stack_bowls-dagger-20260830-seed1/
    ├── robodojo-fold_towel-official-100ep/
    └── ...
```

## 简单规则

- `raw/` 保存完整源数据；批次目录名由使用者指定，转换后也不修改原始数据。
- `lerobot/` 下每个目录都是一份独立的 LeRobot 数据集。
- LeRobot 目录名也由使用者通过转换命令的 `--repo-id` 指定，不自动生成。
- 目录名避免空格和逗号；数据参与训练后不再随意重命名。

## 转换关系

```text
raw/dagger/<任务>/<批次>  ── DAgger 转换器 ──> lerobot/<repo_id>
raw/hdf5/<任务>/<批次>   ── HDF5 转换器   ──> lerobot/<repo_id>
```

## dev-openpi 训练如何找到数据

训练前，把统一的 LeRobot 根目录告诉数据加载器：

```bash
export HF_LEROBOT_HOME=/mnt/resource/robodojo_dataset/lerobot
```

训练配置中的 `repo_id` 就是 `lerobot/` 下的目录名：

```python
repo_id="robodojo-stack_bowls-official-100ep"
```

同时使用多份数据时，用逗号连接多个目录名，不需要再复制出一份合并数据：

```python
repo_id=(
    "robodojo-stack_bowls-official-100ep,"
    "robodojo-stack_bowls-dagger-20260830-seed1"
)
```
